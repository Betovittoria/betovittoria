### 🏛️ Engineering Philosophy

> *"Code without architectural understanding is just technical debt waiting to happen. Build on solid foundations: clean component separation, strict standards, and relentless performance."*

I design and build **high-converting web applications, resilient frontend architectures, and automated agentic systems**. My engineering approach balances aesthetic perfection (Linear/Vercel tier UX) with solid computer science fundamentals:

* **Clean / Component-Driven Architecture:** Decoupled business logic, presentation containers, and tokenized design systems.
* **Extreme Performance & Core Web Vitals:** Sub-second TTFB, optimized asset pipelines, and zero-bloat JavaScript bundles.
* **AI-Augmented Development (SDD):** Using Spec-Driven Development and autonomous agentic workflows to ship robust production features with speed and verified rigor.
